# AI Hackathon Practice Toolkit

This repository contains reusable practice materials for AI-assisted programming.

## Purpose
- Practice using GitHub and Codex CLI
- Learn requirement analysis and task planning
- Verify generated code with automated tests
- Document results, errors, and limitations

## Workflow
1. Read the project requirements.
2. Identify unclear conditions.
3. Plan and implement the solution.
4. Run tests and inspect the outputs.
5. Document the results.

## Notes
This repository contains general-purpose practice materials only.
